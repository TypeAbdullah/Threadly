# User Reports

Community members can flag inappropriate content for moderator review.

## Report Categories
- **Spam**: Promotional links, crypto airdrops, unsolicited advertising.
- **Harassment**: Target abuse, personal attacks.
- **Hate Speech**: Discrimination or hate.
- **Sexual Content**: Explicit material.
- **Violence**: Threats or violent speech.
- **Spoiler**: Unmarked plot spoilers.
- **Other**: Custom report details.

## Anti-Abuse Prevention
A unique compound database index on `(commentId, userId)` ensures that a single user cannot spam multiple reports on the same comment.
