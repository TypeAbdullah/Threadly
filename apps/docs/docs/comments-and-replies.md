# Comments and Replies

Discussions are structured into root comments and nested replies.

## Strict Exclusion of Reactions
To prevent superficial vote manipulation, toxic downvoting, and algorithm distortion, Threadly **intentionally does not implement comment reactions, likes, or vote counts**.

## Ranking Algorithm ("Best" Sort)
The `best` sorting order ranks comments based on:
1. **Discussion Activity**: Number of threaded replies.
2. **Time Decay**: Age weighting formula preventing old comments from dominating indefinitely.
3. **Moderation Status**: Clean, verified comments prioritized.
