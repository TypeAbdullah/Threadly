# Authentication

Threadly utilizes **Better Auth** with official MongoDB adapters.

## Supported Providers
- **Google OAuth**
- **Discord OAuth**

## User Profile Customization
Users customize their Threadly identity independently of OAuth provider usernames:
- **Display Name**: The name displayed prominently on comments.
- **Username**: Unique `@handle` (alphanumeric + underscores).
- **Bio**: Custom bio up to 500 characters.
- **Avatar Decoration**: Custom ring badges (e.g. Cyber Neon, Crimson Flame, Golden Wreath).
